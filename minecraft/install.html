Download and Install

How to install Ritual Archive for Minecraft 1.21.1: Java, NeoForge, the mod, and a server if you want one.

Section I

Get the mod

One file, and nothing else to download with it.

The easy way, on Windows

Download the Ritual Archive launcher (under 1 MB). It's a test version. You need to own Minecraft: Java Edition. It never asks for your password: you sign in to Minecraft's own launcher, as usual.

  1. Open the Minecraft Launcher, sign in, and close it. It has to be closed for the next steps.
  2. Run the file you downloaded. Your browser may warn about it first; choose to keep it. Windows may then say "Windows protected your PC", because the launcher isn't signed: choose More info, then Run anyway.
  3. On the Minecraft row, press Install. It downloads Java for this step only, NeoForge and the mod, which takes a minute or more.
  4. When the button says Play, press it. The Minecraft Launcher opens.
  5. In the Minecraft Launcher, choose Ritual Archive next to its Play button, then press Play.

If something goes wrong, the launcher says what happened. Press Copy details and send that to whoever is helping you; it may show folder names from your computer. To play with a friend, use Play together: it shows your address and tests theirs. Everyone needs the same version of the mod. The steps below are for doing it by hand.

Section II

Check Java

NeoForge's installer needs Java, and you install that yourself.

  1. Open a terminal and run java -version.
  2. If you get an error, or the first number isn't 21, install 64-bit Java 21. On Windows and macOS, Adoptium has an installer. NeoForge's guide covers Linux too.
Section III

Install NeoForge

For the official Minecraft launcher. Other launchers have their own steps.

  1. Close the Minecraft Launcher.
  2. Download the NeoForge 21.1.265 installer. Use this link rather than the button on neoforged.net: that page starts on a much newer version, for a different Minecraft, and the mod won't run on it.
  3. Open the file you downloaded. Make sure Install client is selected, then click Proceed.
  4. Open the Minecraft Launcher. A NeoForge option should now be there. If it isn't, go to Installations and tick Modded.

NeoForge recommends a separate profile, which keeps your mods away from your normal game:

  1. In the launcher, go to Installations and click New Installation.
  2. Give it a name and select the NeoForge version you just installed.
  3. For the game directory, choose a folder of its own, outside the standard .minecraft folder.
  4. Click Install.
Section IV

Add the mod

It goes in the mods folder of that profile.

  1. Start the NeoForge profile. On the title screen, click Mods, then Open Mods Folder. That opens the right folder, wherever it is on your computer.
  2. Put ritualarchive-0.1.0-neoforge-1.21.1.jar in that folder. Leave it as a .jar, and don't unzip it. Windows can hide file extensions, so a renamed file can end up as .jar.jar without showing it. The name should end in one .jar.
  3. Close the game, start the profile again and join a world. The Awakening opens by itself when you first join, which tells you the mod is running. Your first session carries on from there.
Section V

Multiplayer and servers

The server and every player need the mod.

The mod's official server is 209.192.186.247:25678. Install the mod as above, then in Minecraft choose Multiplayer, Add Server, and paste that in. The launcher shows it too, with a Copy link.

The official server also runs three other mods, with the libraries they need. Every player needs exactly these versions, or the server turns them away on joining. The launcher's Install and Update buttons fetch all of them from their official pages and check each one, so with the launcher there's nothing more to do. Installing by hand? Put these in the same mods folder as ours:

  • Twilight Forest 4.8.3345 (twilightforest-1.21.1-4.8.3345-universal.jar)
  • Simply Swords 1.70.2 (simplyswords-neoforge-1.70.2-1.21.1.jar)
  • Mowzie's Mobs 1.8.2 (mowziesmobs-1.21.1-1.8.2.jar)
  • Libraries: GeckoLib 4.9.3, Architectury API 13.0.11, Fzzy Config 0.7.7+fix1, Simply Tooltips 0.1.5 and Kotlin for Forge 5.12.0, all for NeoForge 1.21.1.

One helper, not needed to join: Just Enough Items 19.44.0.401 (jei-1.21.1-neoforge-19.44.0.401.jar), the item and recipe list beside your inventory. It runs on your own game only, so the server doesn't need it. The launcher installs it with the rest.

These mods belong to their own authors. We don't host their files; the launcher downloads them from CurseForge and Modrinth.

Players install it as above. To set up a dedicated server of your own:

  1. Download the same NeoForge installer into the folder you want the server in.
  2. In a terminal in that folder, run java -jar neoforge-21.1.265-installer.jar --installServer. Use the name of the file you downloaded, if it's a newer version.
  3. Start the server with run.bat on Windows or ./run.sh on Linux and macOS. It shuts down by itself the first time.
  4. Open eula.txt and change eula=false to eula=true. This means you agree to the Minecraft EULA.
  5. Start the server again, then stop it. This makes the mods folder and server.properties.
  6. Open server.properties and change allow-flight=false to allow-flight=true. Many techniques let you fly, and without this the server kicks anyone flying with them.
  7. Put the same ritualarchive-0.1.0-neoforge-1.21.1.jar in the server's mods folder and start it.

On a rented server, set allow-flight=true in the host's settings or its server.properties, then restart it.

Its settings are listed under Server settings.

Section VI

How far this has been checked

This guide has been followed on a real install, and it worked. A few steps have been reworded since, so tell the owner if one doesn't match what you see. The owner has played the mod with a second player, on the same network and on different networks, and both went smoothly. An earlier build of the test jar loaded and opened a world on NeoForge 21.1.265. The build here has been compiled from the mod's code, and hasn't been installed on a clean game or a real server yet. This build is commit 87b12c5. The last automatic crash test with a game window came out with no errors on commit 1ae9fe4, on 9 November 2026. Everything changed since then has passed tests without a window only, which check rules and numbers, not what you see. The crash test shows nothing crashed, not that everything looks or plays right. The launcher has run a real install into test folders, and no person has used it yet. The NeoForge steps follow its own guides for the client and the server, as they read on 5 November 2026. That the server and every player need the mod comes from reading the mod's code.

Known problems in this build: in rare cases, /stop on a server may never finish; it's been seen in one test and its cause isn't known. A character whose flight from a technique got stuck in an older build keeps it until you run /gamemode creative and then /gamemode survival.

If NeoForge itself gives you trouble, it has a troubleshooting page.
